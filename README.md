# 윤곽 카메라 (EdgeCam)

카메라 화면을 실시간으로 **전부 검정 + 흰색 윤곽선만** 보이게 바꿔주는 안드로이드 앱.

- 감도 슬라이더: 오른쪽으로 갈수록 윤곽선이 많이 보임
- 선 굵기 슬라이더: 선을 더 굵고 진하게
- 카메라 전환: 앞/뒤 카메라
- 촬영: 지금 화면을 PNG로 저장 (갤러리 → Pictures/EdgeCam)
- 화면을 한 번 탭하면 조작 패널이 숨겨짐 / 다시 탭하면 나타남

안드로이드 10 이상에서 동작. 외부 라이브러리 없이 안드로이드 기본 기능만 사용.

## APK 만드는 법

### 방법 1. GitHub로 (PC에 아무것도 설치 안 해도 됨)
1. GitHub에서 새 저장소를 만들고 이 폴더 안의 파일 전부를 업로드
   (`.github` 폴더도 꼭 포함)
2. 저장소의 **Actions** 탭 → "Build APK" 실행이 끝날 때까지 몇 분 기다림
3. 끝난 실행을 눌러 아래쪽 **Artifacts**에서 `EdgeCam-apk` 다운로드 → 압축 풀면 `app-debug.apk`
4. 폰으로 옮겨서 설치 ("출처를 알 수 없는 앱 설치" 허용 필요)

### 방법 2. Android Studio로
1. Android Studio에서 **Open** → 이 폴더 선택
2. 폰을 USB로 연결(개발자 옵션의 USB 디버깅 켜기) 후 ▶ Run
   또는 Build → Build APK(s)
