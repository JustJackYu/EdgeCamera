# 윤곽 카메라 (EdgeCam)

카메라 화면을 실시간으로 **전부 검정 + 흰색 윤곽선만** 보이게 바꿔주는 안드로이드 앱.

**최신 APK 받기:** https://github.com/JustJackYu/EdgeCamera/releases/latest/download/EdgeCam.apk

## 기능
- 감도 슬라이더: 오른쪽으로 갈수록 윤곽선이 많이 보임
- 선 굵기 슬라이더: 선을 더 굵고 진하게
- 카메라 전환: 앞/뒤 카메라
- 촬영: 지금 화면을 PNG로 저장 (갤러리 → Pictures/EdgeCam)
- 숨기기: 버튼·슬라이더·시스템 바를 전부 숨김. 화면을 탭하면 다시 나옴
- VR 모드: 가로 화면 + 왼쪽/오른쪽 눈용 화면 2개 (폰 VR 기기용)
  - 메뉴가 숨겨진 상태에서는 **볼륨 + / −** 로 감도 조절
  - 화면 탭 → 메뉴 표시, **뒤로가기** → VR 모드 종료
- 업데이트: 앱을 켤 때 새 버전이 있으면 알려줌. "업데이트" 버튼으로 직접 확인도 가능.
  받은 EdgeCam.apk를 열면 기존 앱 위에 덮어 설치됨 (설정·사진 유지)

안드로이드 10 이상에서 동작. 외부 라이브러리 없이 안드로이드 기본 기능만 사용.

## 빌드
`main`에 올리면 GitHub Actions가 APK를 만들어서 Releases에 `build-N`으로 올림.
모든 빌드는 `keystore/edgecam.jks` 한 개의 키로 서명되므로 계속 덮어 설치(업데이트)할 수 있음.

Android Studio로 직접 빌드하려면: **Open** → 이 폴더 선택 → ▶ Run.
